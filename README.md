About: 
This repository contains a Jupyter Notebook developed as part of the Deep Learning course at Toronto Metropolitan University (TMU). The project focuses on building a Visual Question Answering (VQA) model that can answer natural language questions based on image input.

Overview: 
Visual Question Answering (VQA) is a challenging AI task that combines computer vision and natural language processing. This project implements aVQA pipeline using deep learning techniques using CUDA to highlight using LLM models and various image extraciton models, integrating image and text features to generate relevant answers.
